# MARU WeChat 음성 통역 · 영어 경유 검증 V0.4.0

이 프로젝트는 기존 BIGO 실시간 통역 V0.3.1에 **위챗 음성 번역 테스트 화면**을 추가한 시험판입니다.

## 새로운 시험 화면

- `위챗 한국어 ↔ 중국어 음성 번역 테스트` 버튼으로 이동
- 한국어 마이크: 한국어 원문 → 영어 → 중국어 최종 번역 → 중국어 음성 읽어주기
- 중국어 마이크: 중국어 원문 → 영어 → 한국어 최종 번역 → 한국어 음성 읽어주기
- 역번역: 최종 번역 → 영어 → 원래 언어로 다시 번역해 원문과 비교
- 텍스트 입력으로 같은 경로 시험, 번역 방향 전환, 최종 음성 다시 듣기
- 마이크 음성 인식은 단말에 설치된 Android 음성인식 앱을 사용하고, 번역에는 MyMemory HTTPS 무료 시험 API를 사용합니다.
- 통화 음성·인식 텍스트는 단말 내 앱에 영구 저장하지 않습니다. 음성인식 서비스와 번역 API에 관련 데이터가 전송될 수 있습니다.
- 무료 번역 API는 익명 기준 하루 5,000자 제한, 문장당 최대 500바이트 등의 한도가 있습니다. 이 앱은 상용 무제한 통역 서비스가 아닙니다.

## 실제 WeChat 음성 통화에는 무엇을 사용하나요?

**삼성 공식 Galaxy AI 실시간 통역**을 사용합니다. 삼성의 2026-10-21 안내에 따르면 WeChat은 지원 앱에 포함됩니다.

1. 설정 → Galaxy AI → 통화 어시스트 → 실시간 통역 켜기
2. 내 언어 한국어, 상대방 언어 중국어(간체) 선택 및 필요한 언어팩 받기
3. 같은 화면에서 '다른 앱에서 실시간 통역' → WeChat 활성화
4. WeChat 음성통화가 **연결된 뒤** 위에서 빠른 설정창을 두 번 내려 '실시간 통역' 선택

**한계:** 위챗 음성통화의 양쪽 오디오는 일반 제3자 앱이 안정적으로 캡처하거나 위챗 상대에게 주입할 수 없습니다. 따라서 영어를 거친 2단계 변환은 이 앱의 독립 테스트에만 적용되고, 실제 위챗 통화 중에는 삼성 통화 통역을 사용해야 합니다. 영어 경유는 오류를 오히려 늘리고 속도를 늦출 수 있으며 100% 정확도는 보장할 수 없습니다.

## 별도 설치

- 시험용 APK는 패키지 이름 끝에 `.wechattest`를 붙여 기존 MARU 앱과 별도로 설치되도록 빌드합니다.
- Android 기본 디버그 인증서로 서명한 시험용 APK입니다. 새로 빌드한 APK는 인증서가 달라져 기존 시험판을 덮어쓰지 못할 수도 있습니다.

## 빌드

GitHub Actions에서 `Build MARU LIVE INTERPRETER V0.4.0 WECHAT RELAY TEST APK` 실행 후 Artifacts의 APK를 내려받으세요. Android SDK 36/Gradle 8.13/JDK 17을 사용합니다.

## 기존 기능

기존 BIGO 전용 한국어 음성 인식, 다국어 번역, TTS, 오버레이 및 자동 일상대화 기능은 유지됩니다. 기존 기능은 WeChat 통화에 대한 직접 오디오 캡처 기능이 아닙니다.
