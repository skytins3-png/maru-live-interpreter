# MARU 실시간 음성 통역 V0.2.0 양방향 시험판

## 이번 시험판에서 확인할 기능

1. 한국어 음성 인식
2. 영어, 중국어, 일본어, 러시아어, 방글라데시어 번역
3. 휴대폰 TTS를 이용한 낮고 부드러운 음성 재생
4. BIGO LIVE 위에 움직일 수 있는 작은 통역 버튼 표시
5. 상대방 외국어 음성의 언어 자동감지
6. 상대방 외국어를 한국어 자막과 한국어 음성으로 변환
7. 감지한 상대방 언어를 답변 언어로 자동 선택

## 중요한 제한

- `내가 한국어로 말하기`는 형의 말을 선택 언어로 번역합니다.
- `상대방 외국어 듣기`는 영어·중국어·일본어·러시아어·방글라데시어를 자동감지해 한국어로 번역합니다.
- 자동감지는 Android 14 이상의 기기 음성엔진을 우선 사용하며, 음성엔진에 따라 감지 기능이 지원되지 않을 수 있습니다.
- 번역에는 인터넷이 필요하며, 공개 시험 번역 서버는 사용량 제한이 있습니다.
- Android 정책상 BIGO LIVE와 마이크를 동시에 사용할 때 한쪽이 무음이 될 수 있습니다.
- BIGO가 상대방 재생음 캡처를 허용하지 않으면 스피커로 나온 소리를 마이크가 다시 듣는 방식으로만 시험됩니다.
- 번역 음성은 우선 휴대폰 스피커로 재생됩니다. BIGO 마이크 직접 주입은 지원하지 않습니다.
- 휴대폰에 대상 언어 TTS 음성이 없으면 설정에서 해당 음성을 내려받아야 합니다.
- 실제 사람의 목소리 복제 기능은 이 시험판에 포함하지 않았습니다.

## 설치 후 순서

1. 마이크 권한 허용
2. 통역할 언어 선택
3. `한국어로 말하기` 버튼을 눌러 단독 시험
4. 정상 작동하면 `비고 위에 작은 통역 버튼 띄우기` 선택
5. `다른 앱 위에 표시` 권한 허용
6. BIGO 분할화면 또는 방송 화면에서 통역 버튼 시험
